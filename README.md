# Automated Flood Risk Detection and Early Warning System

**Author:** Durga Bahadur Basnet

## Overview
This project simulates an Automated Flood Risk Detection and Early Warning System using a Random Forest model, ESP32 sensor simulation, and Robotic Process Automation (RPA) for PDF dossier generation. Designed for simplicity, it runs entirely locally without requiring any external APIs.

## Installation & Execution
1. Open your terminal.
2. Navigate to this project folder.
3. Install the required Python libraries:
   `pip install -r requirements.txt`
4. Run the data simulator and dashboard:
   `streamlit run app.py`
